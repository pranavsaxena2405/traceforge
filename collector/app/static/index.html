What & Why TRACEFORGE

Standard APM tools monitor HTTP status codes and CPU usage, but fail to catch non-deterministic AI failures.

⚠️

The Problem

  • Non-deterministic AI Drifts: Prompt changes unexpectedly degrade downstream tool execution.
  • Token Budget Overruns: Unmonitored recursive loops blow past cost limits.
  • Vector Retrieval Quality: Low document relevancy top_k matches produce silent hallucinations.
⚡

The TRACEFORGE Solution

  • OpenTelemetry Standard: Native OpenTelemetry primitive instrumentation without vendor lock-in.
  • Automated Behavioral CI/CD: Pass/Fail SLA regression checks in pull requests and CI test jobs.
  • Full Span Waterfall Debugger: Complete timeline trees for LLM calls, tool loops, and SQL queries.

Seamless 2-Line Integration

Zero configuration telemetry collection in Python applications.

from traceforge import trace

# Decorator or context manager integration
@trace("customer_support_agent")
def run_agent(prompt: str):
    with trace.span("vector_retrieval", span_type="retrieval"):
        docs = vector_db.query(prompt, top_k=5)

    with trace.span("llm_reasoning", span_type="llm"):
        response = llm.generate(prompt, docs)
    
    return response
# Inspect live traces in terminal
python -m traceforge.cli list

# Render span waterfall hierarchy
python -m traceforge.cli get <TRACE_ID>

# Run automated behavioral CI/CD assertions
python -m traceforge.cli eval <TRACE_ID> --latency 2500 --max-tokens 2000
